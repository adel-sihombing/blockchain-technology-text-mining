# Blockchain Technology - Text Mining

A Python project exploring web scraping, text preprocessing, exploratory data analysis, and feature engineering on scientific articles related to Blockchain Technology.

## Overview

This project was created as part of a Midterm Examination (UTS) for the Data Science program, Class of 2025G.

It explores how Python can be used to collect scientific articles through the Springer Nature API, process textual data, analyze article information, and apply various text representation techniques.

## Purpose

This project provides hands-on practice with web scraping, text preprocessing, data analysis, and feature engineering using Python.
